## 1. `/community` 독립 포털 — dev 전용 게이팅 (PR 머지됨)

배포된 트레이너/회원 앱과 같은 portal 번들이라, Community 를 켜면 운영에도 노출되는 문제. 공개 시점은 사용자가 직접 통제하길 원함.

- `apps/portal/src/App.jsx` — `/community` 라우트를 `import.meta.env.DEV` 로 분기:
  dev = 실제 `CommunityPortal`(lazy import → 별도 chunk), prod = `ComingSoon` 유지
- `apps/portal/src/pages/Landing.jsx` — 커뮤니티 포털 카드 + 푸터 링크를 dev 에서만 렌더
- 빌드 확인: `build:portal` 통과, CommunityPortal 은 prod 에서 미로드 chunk 로 분리

## 3. 회원앱 커뮤니티 탭 제거 (PR 머지됨)

회원앱 커뮤니티 탭은 2개 서브탭(📢 공지사항 읽기전용 + 💬 자유게시판 UGC)으로 구성. 베타 30명에서 자유게시판(UGC)은 사용도 낮은 반면 모더레이션·PIPA·RLS·저장소 부담이 커서, **탭 통째 제거**로 결정 (트레이너 앱과 동일하게 입장 공지 팝업만 유지).

- `apps/portal/src/pages/MemberPortal.jsx` — 커뮤니티 탭 nav 항목 / 렌더 블록 / 글쓰기 모달 / 관련 state·함수(loadPosts·createPost·toggleReaction·deletePost·loadNotices) / FEATURES 항목 / 미사용 helper(REACTIONS·formatRelative) 제거 (296줄 삭제)
- 공지는 기존 `LoginNoticeModal`(입장 시 1회) 로 일원화
- 빌드 통과, 다른 기능(수업일지/체중/운동/식단) 무영향

## 4. 고아 데이터/표면 정리

회원앱 커뮤니티 탭 제거 후 더 이상 쓰이지 않는 DB/스토리지 정리:

  (잔여 데이터 불필요 합의 → 056 RLS 잠금 대신 테이블째 삭제. 056 은 superseded·미머지.)
- **058_drop_community_photos_bucket.sql** — 고아 `community-photos` 버킷 객체/정책/버킷 제거.
  (어떤 앱도 미참조 확인. Dashboard 에서 파일 먼저 비운 뒤 적용 권장.)
- 저장소 잔재 `src/pages/AdminPortal.jsx`(모노레포 분리 전 옛 중복본) — 제거 대상이나 사용자 확인 후 진행 예정.
