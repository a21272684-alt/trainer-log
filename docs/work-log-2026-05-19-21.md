## 1. 머지 완료 — PR #51 (로그인 공지 기능)

**브랜치:** `claude/login-notice` → `main` (2026-05-19, `3131171` → 머지 `67fc346`)
**커밋:** 단일 커밋 `3131171 feat: 로그인 공지 기능 — admin 제어 + 트레이너/회원 앱 모달`

### 요청 배경
트레이너·회원 앱에 로그인 직후 공지 팝업을 띄우고, admin 에서 ON/OFF·대상·문구를 제어할 수 있어야 함. 추가 DB 스키마는 만들지 않는 게 목표.

### 설계 핵심
- **신규 컴포넌트 1개**: `packages/shared/components/common/LoginNoticeModal.jsx`
- **DB**: 기존 `app_settings` 테이블 + 새 키 `login_notice` (JSON) — 스키마 변경 0
- **RPC**: 기존 `app_settings_admin_upsert` 그대로 재사용
- **저장 형태**:
  ```json
  {
    "enabled": true,
    "target": "all|trainer|member",
    "title": "...",
    "snoozeDays": 7,
    "newFeatures": "2026-05-19 | 시간표 평일 기본 표시\n...",
    "upcoming": "회원 자가 운동 입력 개선\n...",
    "updatedAt": "2026-05-19T03:30:00Z"
  }
  ```

### 노출 규칙 (클라)
1. `enabled === true`
2. `target` 매칭 (`all` 또는 현재 앱 타입과 일치)
3. localStorage 스누즈 (`login_notice_snoozed_until` 같은 키) 미경과
4. updatedAt 갱신 → 같은 사용자도 새 공지로 인식, 스누즈 무시 재노출

### UX
- "신규 기능" (✓ 날짜·내용) / "업데이트 예정" (◎ 항목) 2개 섹션, 빈 섹션 자동 숨김
- "N일동안 보지않기" 버튼 → 스누즈 저장
- "닫기" / 배경 클릭 / X → 세션만 닫힘 (다음 로그인 다시 노출)
- aria-modal 적용

### admin 연결
`AdminPortal.jsx` 시스템&법적고지 영역에 **📢 로그인 공지** 카드 추가:
- ON/OFF, 대상 select, 스누즈 일수, 제목, 신규기능 textarea, 예정 textarea
- 저장 시 `updatedAt` 자동 갱신

### 트레이너/회원 앱 연결
- `TrainerApp.jsx`: 메인 진입(screen=app)에 `<LoginNoticeModal target="trainer"/>` 1줄
- `MemberPortal.jsx`: 로그인 후 메인에 `<LoginNoticeModal target="member"/>` 1줄

### 영향
- `app_settings` 읽기 1회 추가 (기존 `feature_gates` fetch 와 동급, 무시할 만한 비용)
- `enabled=false` 또는 키 없음 → 모달 자체 미렌더 (안전 기본값)
- 기존 RPC 시그니처·다른 키·로그인 흐름·DB 스키마 모두 무관

→ **운영 반영 완료.** 이후 사용자가 admin 에서 메시지만 갱신하면 사용자 앱에 즉시 반영됨.

### 두 가지 개선 (서로 연관)

#### A. Prompt 정밀화 — "트레이너 입력만 재해석, 창작 금지"

`buildSessionLogPrompt` 가 그동안 빈 섹션에 일반 조언을 채우거나, 트레이너가 안 적은 운동·증상을 추측해서 일지를 만들던 케이스를 차단.

**3가지 룰 명시:**
1. 트레이너 입력(메모/음성)에 있는 내용만 재구성 — 운동·세트·증상·일반 조언 일체 창작 금지
2. 비어있는 섹션은 채우지 말고 생략
3. 트레이너가 직접 쓴 게 아니면 교과서식 일반 조언 금지

각 섹션(🏋️ 운동 / 💬 회원 반응 / 🎯 코멘트) 헤더에 "입력 없으면 섹션 생략" 명시.

#### B. 관점 칩 4개 → 6개 (유료)

`ai_templates.js` 에 `PERSPECTIVE_TEXT` 매핑 추가 — 칩 값을 풍부한 한국어 lens 설명으로 변환. 알 수 없는 키는 freeform 텍스트로 폴백.

**신규 2종:**
- 🧠 **AK·응용근신경학** (indigo) — 신경역학적 lens. 약화를 강화 대상이 아닌 반사·억제 신호로 해석
- 🌀 **복잡계** (cyan) — 비선형 적응 lens. 시스템 결합(수면·스트레스·호흡)과 임계 효과 고려

### 파일
- `packages/shared/lib/ai_templates.js` — `PERSPECTIVE_TEXT` 맵 + prompt 재작성
- `apps/portal/src/pages/TrainerApp.jsx` — 4 → 6 칩, 주석 갱신

AI 일지 출력이 "입력 충실"·"창작 자제" 방향으로 정밀해짐. 트레이너가 메모만 짧게 적어도 거기 없는 내용을 만들지 않음.
