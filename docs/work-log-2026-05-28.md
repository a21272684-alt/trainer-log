## 1. 전략 (Community 활성화)

- **wedge:** AI 일지/이탈예측 등 1인 강사에게 즉시 ROI 주는 도구로 트레이너 획득 → 그 위에 Community.
- **차별점:** 단순 링크인바이오(리틀리)가 아닌 "오운 인증 데이터 + 회원 동의 비포애프터 + 1:1 연결" 신뢰형 프로필.
- **0원 홍보:** 트레이너가 공개 프로필 링크를 인스타 바이오에 → 잠재 회원 유입 + 오운 노출. 회원 변화 카드 공유 = 바이럴.
- **수익화(후속):** 구독 X. **소비형 크레딧(노출 끌어올리기)** + 일회성 Pro 언락. 기존 029 credits 재활용. 무료 코어로 네트워크부터.
- **콜드스타트:** 좁은 지역/버티컬부터 밀도. 무료 코어가 우선.

## 2. PII / 상담 설계 (저리스크)

- 상담 = **카카오톡 연결**, 오운은 이름·전화 **미수집**. `profile_events`(view/contact_click/pricing_view, 익명)만 기록 → 노출·문의 지표.
- 개인정보 처리는 카카오 위임 → 오운 법적·보안 부담 거의 0. (인앱 리드는 수요 확인 후 최소 PII 로 승급 검토)

## 3. 비포애프터 + 동의 (회원 주도)

- 회원이 **회원 앱 안 "내 변화 공유" 화면**에서 직접 업로드 + 공개 동의 토글 → 트레이너 프로필 노출 (동의 자연 확보).
- 얼굴 가림 기본, 셀프 내리기(revoke) → 민원 CS 소멸. 오운은 상태값만 저장.
- 비용: 클라 압축(`compressImage`) + 버킷 1MB 상한 + 개수 제한 + lazy + 캐시 → 큰 사진도 저비용.

## 4. 데이터 모델 (059)

- `trainer_profiles`(handle·is_public·**display_name**·tagline·bio·specialties·location·photo_url·kakao_link·show_stats)
  - ⚠️ 공개 페이지는 anon → trainers(050 RLS) 못 읽음 → 표시용 이름/사진을 trainer_profiles 에 비정규화 저장(display_name)
- `trainer_packages`(가격, 트레이너 직접 CRUD — 오운 정산 X)
- `member_transformations`(비포애프터 + consent/status)
- `profile_events`(익명)
- 스토리지 `transformations`(public, 1MB, webp/jpg/png)
- RLS: 공개 읽기는 공개 조건만 / 본인 쓰기 / 익명 이벤트 insert. 전부 신규 추가 → 기존 운영 영향 0.

## 5. 구현 (UI)

- **ProfileEditor.jsx** — handle(자동제안+수정+변경경고), 이름·소개·전문분야·위치·카톡·공개토글·패키지 CRUD. TrainerApp 7000줄 분리 원칙대로 독립 컴포넌트. 설정 탭에 "🪪 공개 프로필 관리 (dev)" 버튼+Modal로 진입 (dev 전용).
- **PublicProfile.jsx** — `/t/{handle}` 공개 페이지(시안 ①). 히어로·전문분야·소개·비포애프터·상담(카톡)·가격. 익명 이벤트 기록. dev 전용 라우트, prod 는 홈 리다이렉트.
- 인증 데이터 집계 박스는 후속(060 RPC) — anon 이 logs/attendance 못 읽으므로 SECURITY DEFINER RPC 필요, 스키마 확인 후 작성.
