## 1. 요청 & 브리핑 (구현 전)

사용자가 "무한 가로 스크롤 리뷰 컴포넌트" 요구사항을 제시하며 **현재 구현과 동일한지 체크 + 다르면 작업시간·생태계 위험 브리핑 후 진행** 요청.

### 현재(기존) vs 요청 차이
- 기존: CSS Grid 반응형 격자 + 진입 시 stagger fade (무한 스크롤 아님)
- 요청: CSS keyframes 무한 가로 marquee + hover 일시정지 + 인증 뱃지 + 인스타

### 브리핑 결과 (작업시간 ~1.5~2h, 생태계 위험 낮음)
3가지 결정 사항 도출 → 사용자 선택:
1. **별점**: 유지
2. **인증 뱃지**: `certified:true` 일 때만 노출 (가명 placeholder 는 false) — 표시광고법 회피
3. **모바일**: marquee 유지하되 속도 완화 + tap-to-pause

## 2. marquee 후기 구현 (`58fb456` 중)

### Landing.jsx
- **`ReviewCard` 컴포넌트 추출** — marquee/정적 양쪽 공용 (DRY)
- **무한 스크롤**: CSS `@keyframes ldMarquee{translateX(0)→-50%}`, 카드 2벌 복제로 끊김 없는 루프
- **일시정지**: 데스크 `:hover` paused, 모바일 `onClick` 토글(`ld-mq-paused`)
- **개수 자동 분기** (후속 버그 수정 포함):
  - 0개 → 섹션 숨김
  - 1~2개 → **가운데 정렬 정적 카드** (복제·치우침 없음)
  - 3개+ → marquee, 넓은 화면 채우도록 `reps = ceil(6/n)` 만큼 보강 후 2벌 복제
- **접근성**: `prefers-reduced-motion` → 애니메이션 끄고 수동 가로 스크롤 폴백
- **연출**: 좌우 끝 `mask-image` 페이드, 모바일 속도 완화(28s→45s)

### 카드 레이아웃 — 옵션 2 (상단 큰 배너 이미지)
시안 HTML 3종 비교 제공 → 사용자 **옵션 2(상단 배너)** 선택 + "세로로도 더 크게" 요청.
- 카드 상단 **가로 꽉 + 세로 240px(모바일 210px)** 배너 이미지
- 카드 폭 320→340px
- 사진 없으면 라임 그라데이션 + 이니셜 폴백 (높이 일관 → marquee 흐름 안정)
- 별점 / 후기 본문 / 이름·지역·인스타 / 인증 뱃지

## 4. 실물 확인 중 발견·수정한 버그 2건

### 버그 A — 후기 1개인데 2개로 보이고 좌측 치우침
- 원인: marquee 가 끊김 없는 루프 위해 카드 2벌 복제 → 후기 적으면 ① 중복 노출 ② 전체 폭 < 화면 → 왼쪽 쏠림
- 수정: 개수 자동 분기 (1~2개 정적 가운데 정렬, 3개+ marquee + 화면 채우기) — `58fb456` 에 포함

### 버그 B — 새로고침 시 등록 안 한 후기가 "엄청 많이" 깜빡임 (`622aada`)
- 원인: `reviews` state 가 하드코딩 기본값(`REVIEWS` 가명 3개)으로 초기화 → DB 로드 후 교체. **그 사이 marquee 가 3개를 12장으로 증식**해 가짜 후기 12장이 flash
- 수정: `reviewsLoaded` 플래그 추가 → **DB 응답 전까지 후기 카드 렌더 보류** (개수 무관 차단), 빈 높이로 레이아웃 점프 방지. 성공/실패 모두 게이트 해제
- 미적용 범위: 통계·문제·솔루션 등 다른 DB 연동 섹션도 이론상 동일 flash 가능하나, 기본값이 실제와 비슷해 비가시 → 후기 섹션만 처리 (필요 시 확장 가능)

## 5. 다음 액션 (사용자)

### 즉시 — Storage 버킷 마이그레이션 1회 (사진 업로드 전제)
Supabase Dashboard → SQL Editor → New query → 아래 실행:
```sql
INSERT INTO storage.buckets (id, name, public, file_size_limit, allowed_mime_types)
VALUES ('landing-assets','landing-assets',true,3145728,
  ARRAY['image/jpeg','image/jpg','image/png','image/webp','image/gif'])
ON CONFLICT (id) DO UPDATE
  SET public = EXCLUDED.public, file_size_limit = EXCLUDED.file_size_limit,
      allowed_mime_types = EXCLUDED.allowed_mime_types;

DROP POLICY IF EXISTS "allow_all_landing_assets" ON storage.objects;
CREATE POLICY "allow_all_landing_assets" ON storage.objects
  FOR ALL USING (bucket_id = 'landing-assets')
  WITH CHECK (bucket_id = 'landing-assets');
```

### 운영 검증
1. ownapp.kr → RESULTS 섹션: 후기 1개면 가운데 정렬, 3개+면 자동 스크롤, 새로고침 시 flash 없음
2. 마이그레이션 후 admin → 후기 사진 업로드 + 인증 토글 테스트
